
# SecureCheck Pro 🔐

## About the Project
SecureCheck Pro is a web-based password strength checker developed using Python and Flask. It evaluates password strength and provides suggestions to help users create stronger passwords.

## Features
- Password strength checking
- Weak, Medium, Good, and Strong classifications
- Password score out of 100
- Show and Hide password option
- Security checklist
- Password improvement suggestions
- Common password detection
- Repeated character detection
- Predictable sequence detection

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## How to Run the Project

1. Install Python.
2. Install Flask:

```bash
python -m pip install flask
```

3. Open the project folder in VS Code.
4. Run:

```bash
python app.py
```

5. Open this address in your browser:

```text
http://127.0.0.1:5000
```

## Project Purpose
The purpose of SecureCheck Pro is to help users understand basic password security requirements and improve their password strength.
